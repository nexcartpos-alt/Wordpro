# Changelog

## 0.3.0
- Real page view with a gap between pages, forced page breaks, page gap setting
- Paste pictures from the browser, screenshots or files (Ctrl+V); right-click menus for text and pictures
- Picture editor: crop, rotate, flip, brightness, contrast, grayscale, sepia, invert; resize and save picture
- Pictures included in HTML export
- GitHub setup: CI, release builds for Windows, macOS and Linux, project website

## 0.2.0
- Symbols: picker window (Ctrl+M), ~300 Unicode math and text symbols, search, recent
- LaTeX-style shortcuts (\\alpha + Space), quick math row, equation templates
- Proper full-size page with Letter / A4 / Legal / A5, margins, landscape
- Vector icon set drawn in code
- Fixed a compile error; builds on JDK 8+

## 0.1.0
- First multi-file version: ribbon, styles, lists, find/replace, pictures, tables, RTF/TXT/HTML, AutoSave
